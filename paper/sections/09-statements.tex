\section*{Data and Code Availability}
\label{sec:statements}
The source code of BlinkTwin, the analysis scripts, the simulation code, the result files and the scripts that produce every figure and table are at \url{https://github.com/r11up/BlinkTwin}; the version described here is tagged \texttt{v1.0-arxiv}, and the code is released under the MIT licence. The application runs in a current browser with no installation. The TypeScript scripts run directly in Node.js 22.6 or later (type stripping), and the Python analyses use Python 3.13 with pinned packages; the repository's README lists the commands that reproduce every number. OpenNeuro ds004902 is openly available~\cite{xiang2024ds004902}. DROZY is available from the University of Li\`ege under a research-only licence that does not permit redistribution~\cite{massoz2016ulg}; it is not included, a script downloads it for users who accept its terms, and only aggregate results derived from it are reported or stored in the repository.
