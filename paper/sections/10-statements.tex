\section*{Data and code availability}
The source code of BlinkTwin, the analysis scripts and the simulation code are at \url{https://github.com/r11up/BlinkTwin}. The repository is private while the manuscript is prepared and will be made public on submission. OpenNeuro ds004902 is available from OpenNeuro \citep{xiang2024ds004902}. DROZY is available from the University of Li\`ege repository under a research-only licence that does not permit redistribution \citep{massoz2016ulg}; it is therefore not included in the repository, and a script downloads it for users who accept its terms. Only aggregate statistics derived from DROZY are reported.
